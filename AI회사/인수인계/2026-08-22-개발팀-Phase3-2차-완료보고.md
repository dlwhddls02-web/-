# Phase 3 · 2차 완료 보고 — 결제부터 이메일까지 전 구간 연결

## 만든 것

**결제 실연동 구조**: `/api/order`(주문 생성, orderId=리딩 id) → `/pay`(토스페이먼츠 결제위젯 v2 + 이메일 입력, 키 없으면 개발 스텁) → `/pay/success` → `/api/pay/confirm`(서버 승인 + 금액 검증 + 멱등 + 실패 재트리거) → premium 생성 → `/report/[id]`. 토스 테스트 키 2개만 .env에 넣으면 실위젯 가동.

**Supabase 전환 준비**: `lib/store-supabase.ts` 어댑터 + `supabase/migration-001-readings.sql`(RLS: 서버 전용) + env 스위치 — URL·서비스키 설정 시 파일 저장소에서 자동 전환. ⚠️ 프로젝트 생성은 대표 계정에서 (무료 티어면 비용 0 — 개설만 해주면 마이그레이션은 개발팀이 적용).

**이메일 발송**: 리포트 완성 시 영구 링크 발송(`lib/email.ts`, Resend). 키 없으면 로컬 큐 기록 — E2E에서 큐 기록 확인됨.

**복원력**: 생성 중단 시 턴 체크포인트에서 재개(`cachedTurns`) — 실제로 이번 실측 중 프로세스가 한 번 죽었고, 재트리거로 턴2부터 이어서 완주했다. 이 복원 경로가 실전 검증된 것 자체가 수확.

**배포 가이드**(README): 유료 생성 15~20분 → Vercel 단독 불가, 생성 워커 분리(Railway/Fly) 또는 컨테이너 호스팅 권장. .env.example, 법적 요건 체크리스트 포함.

## E2E 검증

주문 → 스텁 결제 승인 → 3턴 생성(중단·재개 포함) → 40,344자 리포트 저장 → 폴링 조회 → 이메일 큐 기록. 전 구간 통과.

## ⚠️ 유료 원가 실측 — 목표 초과, 대표 결정 필요

실측(재개 시나리오): 4,756원 + 턴1분 약 1,400원 = **건당 약 6,100원** (무중단 이상 경로 추정 ~5,500원). 원인은 캐시가 아니라 **출력 토큰**이다 — 3턴 합계 출력 ~46,000토큰이 원가의 80%를 차지하고, 이건 캐싱으로 못 줄인다. 9,900원 판매 시 마진 ~38%, 무료 리딩 원가 1,400원을 전환율로 나눠 얹으면(전환율 20% 가정 시 +7,000원/건) **적자다.**

선택지: ① 출시가를 14,900원으로 상향(기획서의 인상 계획 조기 실행) — 마진 ~55%, 무료 원가 흡수 가능 ② 유료 분량 축소(로드맵 턴 출력 절반 → 원가 ~4,000원) — 소름 품질 리스크 ③ 무료 리딩을 요약형(짧게)으로 — 전환 엔진 약화 리스크 ④ 조합(가격 12,900 + 무료 스트리밍 앞부분만 노출). 개발팀 의견: **①이 안전하다** — 치킨쿠폰·용용 대비 분량과 품질이 프리미엄을 정당화하고, 무료 과거 리딩의 전환력이 이 가격을 받쳐줄 가능성이 높다. 단 가격은 대표 소관.

## 3차 남은 일

토스 테스트 상점 개설(대표) → 실위젯 왕복 테스트, Supabase 프로젝트 생성(대표) → 마이그레이션 적용, Resend 도메인 인증, 개인정보처리방침·사업자 표기 페이지, 호스팅 결정·배포, 태정 피드백 반영, 디자인 폴리시(오행 차트 줄바꿈 등 3건).
