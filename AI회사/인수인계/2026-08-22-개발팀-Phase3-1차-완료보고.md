# Phase 3 · 1차 완료 보고 — 웹 서비스가 돌아간다

## 오늘 만든 것

**PHASE3-SPEC 전면 개정** — 구 9챕터 파이프라인 폐기를 명문화하고, 검증된 최종 아키텍처(만세력 표 + 자유해석 3턴 + 용용 이식 장치 + 안전 규칙)를 스펙으로 고정했다. "정확도 200%" 문구 사용 금지와 변형 슬로건 가안("계산 100% + 소름 100%")도 스펙에 반영.

**생성 모듈 서비스 승격** (`saju-engine/src/freereading.ts` + `safety.ts`) — 테스트 스크립트로 돌리던 3턴 자유해석을 서비스 모듈로: free(턴1)/premium(턴1~3) 티어, 스트리밍+끊김 이어쓰기, 턴별 체크포인트(중단 재개), 프롬프트 캐싱(cache_control), 위기 문구 감지 시 109 안내 고정+명리 소재화 금지 프롬프트 주입, usage·원가 집계. **무료 1건 실측 원가 1,379~1,413원** (만세력 블록 캐시 적재 확인 — 유료 턴2·3은 접두사를 1/10 가격으로 재사용).

**Next.js 웹 앱** (`saju-web/`) — 랜딩(네이비 히어로, 레퍼런스 리포트 무드) → 입력(생년월일시·성별·출생지 17개 시도 경도 매핑·시간모름·**고민 500자**) → 무료 결과(4기둥 오행색 카드, **계산 과정 타임라인**(서머타임·진태양시·절기 — 우리만의 신뢰 장치), 오행 차트(검증 팔레트), 연도별 격발 강도 라인차트(지수 명시 "금액 아님"), **무료 리딩 SSE 실시간 스트리밍**) → 유료 CTA(9,900원, 청약철회 고지) → 리포트 뷰어(목차 네비게이션, 생성 단계 표시 폴링, 영구 링크 고지, 면책 푸터).

## 검증 결과

엔진 회귀 **25/25** (준형·은혜 레퍼런스 명식 2건 추가 — PDF의 기둥·대운수와 완전 일치), 프로덕션 빌드 통과, `/api/calculate` 값 = 엔진 검증값 일치(辛未 辛卯 甲午 己巳·수0·역행6·보정 10:57), 무료 리딩 SSE 엔드투엔드 1건 실생성 성공(7,799자, 저장·폴링 조회 확인).
