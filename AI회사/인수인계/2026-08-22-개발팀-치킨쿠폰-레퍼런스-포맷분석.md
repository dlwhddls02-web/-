# 치킨쿠폰 레퍼런스 분석 — 실증된 "소름 포맷"의 해부

용용 3종은 경쟁사 벤치마크였다. 이 3종은 다르다 — **우리 최종 아키텍처(만세력 표 + 자유해석)가 실제로 만들어낸 출력이고, 제3자(리포트의 주인공들)가 소름을 실증했다.** 즉 이건 벤치마크가 아니라 하우스 스타일의 원형이며, Phase 3 렌더러와 프롬프트가 재현해야 할 타깃이다.

## 1. 리포트 공통 뼈대 (개인사주 2종, 각 6페이지)

표지(한자 제목 四柱分析報告書 + 이름 + 일주·생년월일시 + 팔자 한 줄 + 작성월) → Ⅰ. 사주 원국: 십성·천간·지지·십이운성·신살 풀테이블 + 합충 요약 각주 + 오행 분포표(비율·의미·**상태 판정: 과다/부족/용신/적정**) + **핵심 요약 박스**(비유 포함 한 문단 총평) → Ⅱ. 원국 심층 분석 6코너 → Ⅲ. 신살·길성 표(위치+의미와 발현) + 직업 적성 결론 박스 → Ⅳ. 대운 흐름 표(전체 대운 십성·핵심 키워드, 현재 대운 하이라이트) + 현재 대운 상세 ①②③ → Ⅴ. 연도별 세운 전망 2026~2032(해마다 명명된 제목 + ★ 핵심 해) → Ⅵ. 실행 전략 4개 + 총평 박스 + 면책 문구 + "원국 데이터 출처: 점신 만세력".

네이비+오렌지 톤, 표와 박스 중심, 페이지당 정보 밀도 높음. 6페이지 = 용용 27장 카드와 정반대 포맷인데도 소름이 나왔다 — **소름은 분량이나 카드 UI가 아니라 아래 문체 장치들에서 나온다는 증거.**

## 2. 소름을 만든 문체 장치 8개 (프롬프트/렌더러에 코드화할 것)

1. **명명된 코너 제목** — "무오(戊午) 병존 — 태양 두 개를 품은 큰 산", "무식상 — 출구 없는 큰물", "정임합 둘 — 재물이 나와 묶였다, 그러나 쟁합". 명리 개념 + 비유 + 그 사람의 상황이 제목 한 줄에 압축된다. 용용의 비유 시스템과 같은 역할인데 더 정밀하다.
2. **구조 → 삶의 패턴 → 처방의 3단 코너** — 모든 코너가 "당신 사주에 X가 있다(계산) → 그래서 삶에서 이런 패턴이 나타난다(단언) → 그러니 이렇게 하라(실행)"로 끝난다. 근거 없는 단언이 없다.
3. **좁은 심리 단언** — "남이 뭐라 하지 않아도 자기 기준에 못 미치면 속을 끓이고, 쉬면서도 마음이 일에 가 있는 유형", "서운함을 말하지 않고 삭이다 멀어지는 패턴". 오오자형·무식상이라는 계산 근거에서 도출.
4. **규칙 하나로 요약하는 처방** — "감정은 쌓이기 전, 24시간 안에 짧게라도 말로", "수입은 즉시 내 명의로 잠근다". 기억 가능한 한 문장 규칙. 용용의 나열식 솔루션보다 강하다.
5. **고전 인용 장치** — "壬水用戊 — 큰 강은 무토 제방을 만나야 범람하지 않는다". 권위 + 낭만을 동시에. 우리 참고문헌 표기(⑰ 근거 각주)와 결합 가능.
6. **판정 어휘의 품격** — 궁합 합충표가 길/흉이 아니라 **길/관리**로 판정한다. 나쁜 코드도 "관리 코드"로 부르고 관리법을 붙인다. 겁주지 않으면서 정직하다 — 우리 포지션과 정확히 일치.
7. **★ 핵심 연도와 명명된 세운** — "2028 무신년 — 도약의 예고편 ★", "2027~2028 — 관계 공식화의 창 ★". 연도 콕 집기에 이름을 붙여 기억하게 만든다.
8. **면책 + 출처** — "관계의 실제는 두 사람의 노력과 선택으로 만들어집니다 · 원국 데이터 출처: 점신 만세력". 신뢰 장치. 우리 버전은 "출처: 자체 만세력 엔진(계산 과정 공개)"로 업그레이드 가능.

## 3. 궁합 리포트 — 검증된 신상품

궁합 리포트가 특히 강력하다. 구성: 두 원국 비교표 → 오행 **교차 보완표**("준형→은혜 용신 공급 / 은혜→준형 출구 공급" — 사중 교차) → 일간 배필 코드("서로의 일간이 정확히 상대의 배우자 별" — 계산된 사실의 낭만화) → 신자진 삼합("은혜님이 곁에 있는 것만으로 준형님의 막힌 재물 물길이 뚫린다") → 합충 판정표(길 8·관리 3) → 관계 관리 전략 3개 → 운로 궁합("2027~2028 관계 공식화의 창", 유의할 해 2026·2032) → 총평 "85점 이상, 상급".

소름 포인트: 개인 리포트 2개를 먼저 주고 궁합으로 묶는 **3종 세트** 구성 자체가 선물 상품이다(치킨쿠폰이 온 이유 — 받은 사람이 선물했다). 커플이 서로의 리포트를 공유하고 궁합을 함께 읽는 바이럴 루프. 용용도 궁합 상품이 있지만 개인 2인+궁합 세트 구성은 없다. ⚠️ 상품화 여부·가격(세트 할인) 대표 결정 — 개발 관점에서는 엔진이 2인 명식 교차 분석(합충 교차, 오행 보완, 배우자성 대조, 세운 동기화)만 추가하면 되고 전부 계산 가능한 항목이라 강력 추천.

## 4. Phase 3 반영 사항

렌더러: 위 1의 뼈대를 리포트 템플릿으로 — 원국 풀테이블·오행 상태 판정표·신살 표·대운 표·세운 연대기·판정표(길/관리)·핵심 요약/총평 박스. 용용 분석의 시각 장치(⑫ 게이지·그래프)와 이 표 중심 밀도를 결합.
프롬프트: 문체 장치 8개를 자유해석 힌트로 — 특히 명명된 코너 제목, 3단 코너 구조, 규칙 한 문장 처방, 길/관리 판정 어휘. (기존 ⑬⑳과 통합)
데이터: 이 3종의 명식(준형 戊午일주 신강 무임극·쟁재 / 은혜 壬子일주 금백수청 무식상·정임합 쟁합)을 회귀 테스트 명식으로 추가 — 엔진 판정과 레퍼런스 서술 일치 확인용.
상품: 궁합(2인 교차 분석) 신상품 후보 등록.

## 5. 결론

용용 분석과 합치면 최종 그림이 완성된다: **계산 레이어는 우리 엔진(검증 완료), 해석 레이어는 이 치킨쿠폰 포맷(소름 실증), 프레젠테이션 레이어는 용용의 시각 장치 + 이 리포트의 표 밀도.** 세 레이어 모두 실물 검증된 재료가 확보됐다. PHASE3-SPEC 갱신 준비 완료.
