# 사주앱 상위권 마케팅 방식 조사 (2026-08-23)

## 조사 대상

기획서 §1-1 실측(2026-08-20, App Store KR 라이프스타일 **매출** 순위) 기준 사주앱 상위 5개: **음양관(13위) · 우주고양이 보라(14위) · 자모 Jamo(19위) · 사주핑(23위) · 사주GPT(29위)**. 여기에 MAU/인지도 강자 **점신·포스텔러·헬로우봇**을 참고군으로 추가 조사.

## 결론 먼저 — 3줄

1. **매출 상위 신생 앱들은 광고 물량전을 안 한다.** 자모(X 오가닉), 사주핑(스레드+PR), 사주GPT(SEO+스레드)는 사실상 광고비 0원 구조로 컸다. 돈을 태우는 건 음양관(인스타 퍼포먼스)과 보라(틱톡/메타 숏폼)뿐.
2. **전부 "고민"을 팔지 "사주"를 팔지 않는다.** 음양관은 고민별 상품 11종(재회·임신·커리어·재물…), 사주GPT는 연애 질문("그 사람의 마음, 재회 가능성"), 사주핑은 연애·이직·금전 불안 상담, 보라는 연애 고민. → 어제 대표 결정(고민-중심 리딩 격상)이 시장 방향과 정확히 일치한다.
3. **우리가 바로 베낄 수 있는 모델은 자모다.** 개인 개발자가 X 계정을 '사주 크리에이터'로 키워 무료 풀이 리플라이 → UGC 스크린샷 → 앱 유입 루프로 5개월 만에 매출 상위권. 예산 0원, 사람 1명(콘텐츠는 우리가 생성 가능)으로 재현 가능한 유일한 검증 모델.

## 앱별 요약

### 1. 음양관 (매출 13위, 2025.3 출시)
- **채널**: 인스타그램 퍼포먼스 광고 물량전(커뮤니티에서 "광고 엄청 하는"으로 회자) + 당근 동네업체 프로필 + 카카오톡 채널 + 자사 웹 퍼널(umg.kr).
- **훅**: "좋지않은 팔자도 전부 말씀드립니다"(직설 컨셉) + "청담·한남동 재벌들이 줄 서서 받는", "200만원 상당" 프리미엄 앵커링 + "최대 87% 할인" + 조선 관상감 헤리티지 서사 + "사주를 점이 아니라 데이터로 봅니다".
- **전환 설계**: 오늘의운세·만세력 평생 무료 → 고민별 상품 11종(재회·임신·커리어·살풀이·재물…)을 '냥' 코인으로 판매. 코인 5,900원~170,000원.
- **특이점**: 매출 13위인데 스토어 리뷰 20개 미만 — 오가닉이 아니라 광고→웹 결제 퍼널로 매출을 만드는 구조(추정). 가짜 정가할인 앵커링은 우리 회사 규칙상 금지 영역.

### 2. 우주고양이 보라 (매출 14위, 2023.10 출시)
- **채널**: 틱톡+메타 숏폼 퍼포먼스 광고(운영사 채용공고에 "주 3~4개 소재 제작, ROAS 테스트" 명시, 타깃 10~20대 여성) + 인플루언서 협찬(전용 쿠폰코드 배포).
- **훅**: 고양이 캐릭터 '보라' 감성 동반자 컨셉("연애 박사 보라"), "2년만에 100만명"·"평점 4.8" 사회적 증거.
- **전환 설계**: 무료 오늘의운세+저녁 '보라의 편지'+걷기 리워드(2,000걸음=1젤리) 등 리텐션 장치 → 심층 풀이를 '젤리'로 결제(₩3,300~₩29,900).
- **특이점**: 리텐션 설계가 제일 정교함(편지·걷기·출석). 캐릭터 IP 없는 우리와는 결이 다름.

### 3. 자모 Jamo (매출 19위, 2026.3 출시 — 5개월 만)
- **채널**: **X(트위터) 오가닉 단일 채널.** 공식 계정(@JamoSaju, 팔로워 ~12.8K)이 ①"~한 사주 특징" 리스트 밈 ②연예인 사주 분석 ③팔로워 질문에 명식 풀이 장문 리플라이(1:1 무료 상담)를 상시 운영. 옥 추천 트윗 159만 조회.
- **훅**: "사주과몰입전문가" 톤 + "당연히 이거 무료" + 예쁜 디자인. AI 채팅 하루 2회 무료.
- **전환 설계**: 무료 2회/일 질문 → 저가 구독(주 ₩3,300 / 월 ₩8,800 / 연 ₩59,000). 결제 문턱이 업계 최저.
- **특이점**: 애플 디벨로퍼 아카데미 출신 **1인 개발**. 광고비 0원. 사용자들이 AI 답변 스크린샷을 자발 공유하는 UGC 루프가 성장 엔진. **우리 상황(1인 개발+저예산)과 가장 유사한 검증 모델.**

### 4. 사주핑 (매출 23위, 2025.10 출시)
- **채널**: 스레드 공식 계정(일간별 데일리 운세 랭킹 콘텐츠) + "前 스님 창업자" 스토리 언론 PR + 입소문. 광고 물량 흔적 없음.
- **훅**: **"나를 기억하는 AI 사주 친구"** — 대화가 쌓일수록 맞춤 조언(관계 지속성 소구). "챗GPT보다 정확한 사주 궁합".
- **전환 설계**: 무료 만세력+기본 상담 → 대화에 '핑' 소모, 구독 ₩35,900~₩189,000/월(업계 최고가).
- **특이점**: "사용자 1명이 지인 4~5명을 데려온다"(회사 주장) — 궁합이 2인 콘텐츠라 자체 바이럴. 고가 구독이 통하는 걸 보면 "기억+관계" 소구의 지불의사가 높다는 신호.

### 5. 사주GPT (매출 29위, 2023.10 출시)
- **채널**: 자사 웹 SEO("정확한 무료 사주 사이트" 키워드 선점, 언어별 도메인으로 글로벌 SEO) + 스레드 연예인 사주 콘텐츠 + 보도자료.
- **훅**: 연애 특화("썸의 온도, 그 사람의 마음, 재회 가능성") + "일반 AI 챗봇과 달리 명리학 전문 학습" + 2026년부터 "성인 딥톡"(무검열 상담)으로 챗GPT 대비 차별화.
- **전환 설계**: 웹 무료 시작(가입 없이) → 포인트 소모형(₩9,900~₩77,000). 무료 범위를 점차 좁히는 중(리뷰 불만 확인).
- **특이점**: "GPT" 네이밍으로 '챗GPT 사주' 검색 수요를 흡수. 웹 퍼널 중심이라 우리(웹 우선 전략)와 구조가 같다.

### 참고군: 전통 강자 3사
- **점신**(MAU 1위 ~95만): B2B 입점이 핵심 채널(토스·신한SOL·하나머니·NH올원뱅크 오퍼월). 무료 오늘의운세 → 400명+ 상담사 전화상담(첫 3분 무료) 매칭 수수료. 앱 이름을 매년 "2026 점신…"으로 바꾸는 시즌 ASO. AI 대응: 솔트룩스 제휴 "운세 특화 AI" 개발 발표.
- **포스텔러**(가입 860만): 브랜드 콜라보(세븐일레븐 협업식품 QR, SBS 예능) + B2B 운세 솔루션(제휴 가입 240만). 무료 폭넓게 → '포스' 포인트. 2024 매출 100억+, "포스텔러 AI" 베타 중.
- **헬로우봇**: 퍼포먼스 물량전(분기 100개+ 광고 소재)이었으나 운영사 띵스플로우 폐업·매각(2025.1) — 물량전 모델의 한계 사례.

## 우리가 베낄 것 / 피할 것

**베낄 것**
1. **자모의 오가닉 루프** — X(또는 스레드) 계정을 '사주 크리에이터'로 운영: "~한 사주 특징" 리스트 밈 + 무료 풀이 리플라이 + 우리 강점(계산 과정 공개, 서머타임·진태양시 보정)을 섞은 콘텐츠. 예산 0원으로 시작 가능, 콘텐츠 생산은 우리 엔진+AI가 담당 가능.
2. **고민별 소구** (음양관·사주GPT) — 광고/콘텐츠를 "사주 봐드립니다"가 아니라 "이직 고민, 사주는 이렇게 답합니다"처럼 고민 단위로. 어제 격상한 고민 입력 UI와 한 세트.
3. **스레드 데일리 콘텐츠** (사주핑) — 일간(日干)별 오늘의 운세 랭킹 같은 저비용 반복 포맷.
4. **웹 SEO** (사주GPT) — 우리도 웹 우선이므로 "무료 사주", "만세력 계산" 키워드 페이지는 도메인 확정 즉시 착수 가치.

**피할 것**
1. 퍼포먼스 광고 물량전(음양관·보라·헬로우봇) — 예산도 없고, 헬로우봇 폐업이 반면교사. 기획서 리스크표에도 "마케팅 물량전은 못 이김" 명시.
2. 가짜 정가할인("87% 할인")·검증 불가 사회적 증거("30만명 선택") — 회사 규칙 위반.
3. 캐릭터 IP 신규 구축(보라·사주핑) — 제작비·시간 대비 우리 차별점(정확도·투명성)과 무관.
4. 무검열 성인 콘텐츠(사주GPT 딥톡) — 리스크 대비 무익.

## 시사점 한 줄

시장 검증된 공식은 "**고민 단위 소구 × 오가닉 콘텐츠 × 낮은 결제 문턱**"이고, 우리는 셋 중 둘(고민-중심 리딩, 14,900원 단건)을 이미 갖췄다. 남은 건 오가닉 채널 하나를 정해서 꾸준히 쌓는 것 — 자모가 5개월 만에 증명했다.
