# 브랜드명 확정 + 마케팅 채널 확정 + 영업팀 역할 재정의

## 결론 3줄

1. **브랜드명은 팔자핏.** 8/23부터 걸려 있던 최상위 병목(도메인·SNS 계정·통신판매업 표기·이메일 발신자명이 전부 브랜드명 대기 중이었음)이 풀렸다.
2. **마케팅 채널은 메타·X·스레드·유튜브 4개**, 각 채널에서 **숏폼 + 게시물** 두 형식. 광고비 0원 정책은 그대로 — 채널 확대는 물량전이 아니라 **한 소재를 4곳에 리패키징**하는 것.
3. **영업팀은 "팔자핏을 효과적으로 파는 방안을 고안하는 곳"**으로 역할을 다시 못 박았다. DM 스크립트를 찍어내는 곳이 아니라 판매 경로·제안 구조·전환 설계를 설계하는 곳이고, 결과물은 방안 + 그걸 바로 실행할 물건이다.

## 1. 브랜드명 — 팔자핏

- 서비스명·SNS 계정명·도메인·이메일 발신자명 기준. 사업자 상호(**핫플리케이션**)와는 별개로 간다.
- 폐기된 후보: 정밀사주 · 명식 · 원국 · 일간 · 초분 · 만세.
- 이걸로 해제되는 항목 (8/23 액션아이템 기준):
  - `A3. 브랜드명 확정` → ✅
  - `B1. 도메인 구매` → 착수 가능
  - `B2. Resend 발신 도메인 인증` → B1 이후 가능
  - `B3. SNS 계정 개설` → 착수 가능 (4채널 전부)
  - `C1. 통신판매업 신고` 표기 → 사업자등록증 나오면 바로

⚠️ 아직 안 된 것: **도메인 실제 취득 가능 여부 미확인.** `.com`이 선점돼 있을 수 있으니 계정명과 함께 한 번에 확인하고, 4채널 계정명을 같은 문자열로 통일하는 게 좋다(핸들 불일치는 나중에 되돌리기 어렵다).

## 2. 마케팅 채널 — 메타·X·스레드·유튜브 × (숏폼 + 게시물)

| 채널 | 숏폼 | 게시물 |
|---|---|---|
| 메타(인스타 중심) | 릴스 | 피드 캡션 + 캐러셀 슬라이드 |
| X | 짧은 영상 | 텍스트 스레드 + 무료 풀이 리플라이 |
| 스레드 | 짧은 영상 | 텍스트 연쇄 포스트 |
| 유튜브 | 쇼츠 | 커뮤니티 탭 포스트 (롱폼은 이번 달 대상 아님) |

**운영 원칙 (회사.md §1에 반영됨)**

- 광고비 0원 유지. 채널 4개는 노출 면적을 넓히는 것이지 물량전이 아니다.
- 콘텐츠 1건 = **숏폼 1개 + 게시물 1개**로 만들고, 4채널 규격에 맞춰 자막·길이·해시태그만 바꿔 배포. 채널별로 새로 기획하지 않는다.
- CTA는 4채널 전부 하나로 통일 — **팔자핏 무료 미리보기**.
- 채널별 유입은 **분리 측정**한다(채널별 링크 파라미터 등). 안 그러면 어느 채널이 헛도는지 모른 채 4개를 다 붙들게 된다.

**8/23 경쟁앱 조사와의 관계**: 조사 결론은 "저비용 오가닉 3강 = X·스레드·인스타"였고, 매출 19위 자모가 X 오가닉 단일 채널로 검증한 모델이었다. 이번 결정은 거기에 **메타 릴스와 유튜브 쇼츠(숏폼 유통)를 추가**한 것이다. 조사 결론과 충돌하지 않는다 — 충돌하는 건 "퍼포먼스 광고 물량전"이고 그건 여전히 안 한다.

## 3. 영업팀 역할 재정의

**전**: 살 가능성 높은 사람을 찾고 대화와 결제를 연결한다.
**후**: **사주풀이앱 팔자핏을 효과적으로 팔 수 있는 방안을 고안하는 곳이다.**

- 콘텐츠를 만드는 곳이 아니다(그건 마케팅팀). 마케팅팀이 만든 유입을 **돈으로 바꾸는 경로를 설계**한다.
- 결과물은 아이디어가 아니라 **방안 + 그 방안을 바로 실행할 물건**(스크립트·순서·기준).
- 다루는 범위: 판매 경로 / 제안 구조 / 전환 설계 / 측정.
- 업무에 새로 추가된 것: ①판매 경로 후보를 펼치고 이번 달 돌릴 1~2개를 고르는 단계 ②무료 미리보기 → 14,900원 전환 설계 ③이 방안의 성패를 판단할 숫자 2~3개와 측정 방법.
- 8/23 영업킷(고객 신호 5개 + DM 3종 + 상담 질문 3개)은 폐기가 아니라 **"오가닉 DM 경로" 한 갈래의 실행물**로 남는다. 이제 그 위에 경로 비교와 전환 설계가 얹힌다.

## 4. 다음 팀에 넘기는 것

**마케팅팀** — 4채널 숏폼·게시물 발행안 3세트. 브랜드명이 확정됐으니 `[브랜드명]` 자리표시자 없이 만들 수 있다.

**영업팀** — 팔자핏 판매 방안. 새 [업무] 1번(판매 경로 비교표 → 이번 달 채택 경로 1~2개)부터 시작한다.

**개발팀/종인** — 도메인 취득, 4채널 SNS 계정 개설(핸들 통일), Resend 발신 도메인 인증.

⚠️ **한 가지 짚고 넘어갈 것**: 지금 실행 인원은 종인·형준 2명이고 콘텐츠 생산은 AI가 돕는다 해도 **4채널 × 2형식 동시 시작은 초기에 과부하일 수 있다.** 자모는 단일 채널로 5개월을 쌓아서 매출 상위권에 갔다. 4채널을 다 열되 **주력 2개(예: X·스레드 — 텍스트라 제작 비용이 가장 낮고 무료 풀이 리플라이 루프가 검증됨)를 먼저 매일 돌리고, 메타·유튜브는 같은 소재를 리패키징해 올리는 보조**로 두는 편성을 권한다. 최종 편성은 대표 결정 사항.
