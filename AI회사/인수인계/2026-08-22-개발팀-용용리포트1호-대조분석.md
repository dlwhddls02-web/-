# 용용사주 리포트 실물 대조 분석 (자미두수 + 정통사주)

블로그 후기 기반이던 어제 분석을, 종인이 실제로 받은 리포트 전문을 다 읽고 확정한다. 원문 전체는 `yongyong/report1-jamidusu-full.txt`에 있다.

## 1. 리포트의 뼈대 — 14챕터 4부 구성, 총 27,590자

인트로를 지나 제1부 "나의 별자리 지도"(나는 어떤 사람일까 / 시작과 방향 / 욕구와 결핍), 제2부 "내가 살아갈 세상"(주 무기 / 가장 무거운 과제 / 앞으로 10년), 제3부 "인생의 6대 영역"(재물·직업 / 연애·결혼 / 건강 / 관계: 귀인과 악인), 제4부 "운명을 바꾸는 법"(전환점 / 조심할 시기 / 개운법), 그리고 마무리 "현운의 편지"로 끝난다. 챕터당 약 2,000자로 균일하고, 총량은 우리 유료 자유해석(~3만자)과 거의 같다. 분량에서는 우리가 밀리지 않는다.

서사 순서가 잘 설계되어 있다: 나 → 과거 → 욕구/결핍 → 무기 → 과제 → 10년 → 6대 영역 → 전환점/경고 → 처방 → 편지. "너는 이런 사람이고(신뢰 구축), 이런 걸 겪었고(소름), 앞으로 이렇게 된다(가치), 그러니 이렇게 해라(실행)"의 완결 구조다.

## 2. 실물에서 확인된 소름 장치 — 어제 분석의 수정점 포함

**가장 큰 발견: 용용은 과거를 콕 집지 않는다.** 과거 서술은 "10대와 20대 초반의 큰 운의 흐름 속에서 내면의 갈등을 견뎌내며", "어린 시절 엄격한 기준에 노출되면서 남모를 마음고생을 겪었을 수 있네요" 수준으로 넓고 부드럽다. 문장 어미도 거의 전부 "~일 수 있어요, ~하기 쉬워요, ~했을 가능성이 커요"의 추정형이다. 연도를 콕 집는 것은 전부 **미래**다: 2028년 운명적 인연, 2030년 결정적 도약, 2033년 인생 전환점, 그리고 조심할 해 2026·2028·2030. **즉 우리 무료 리딩(과거 연도 단언)은 용용이 안 하는 걸 하는 것이고, 이건 차별점으로 유지할 가치가 있다.** 대신 우리 유료에는 용용식 "미래 연도 콕 집기"(도약 연도 1개 + 조심할 연도 3개 + 전환점 연대표)를 명시적 코너로 넣어야 한다.

둘째, **심리 서술 자체는 상당히 범용적인데 근거 장치가 개인화를 만든다.** "완벽주의로 스스로를 검열한다, 힘든 걸 혼자 삭인다, 준비가 덜 됐다며 시작을 미룬다" — 사실 누구에게나 어느 정도 맞는 말이다. 그런데 매 단락이 "명궁의 경양과 천형이", "질액궁의 문창 화기가"라며 별 이름을 근거로 붙이니 내 명반에서 나온 말처럼 읽힌다. 우리 방식(십신·대운·세운 근거 병기)과 같은 원리이고, 우리는 계산 과정까지 공개하니 더 밀 수 있다.

셋째, **수치화가 계산된 느낌을 만든다.** 챕터마다 최소 1개의 시각 장치가 있다: 성향 6개 % 게이지, 욕구 5개 %, 분야 적합도 4개 %, 신체 계통 주의도 5개 %, 내면 긴장도 85/여유 40, 도약 원동력 85/집중도 90, 부의 그릇 75/100, 독립↔화합 슬라이더, 지나온 운 타임라인, 앞으로 10년 2년 단위 그래프, 전환 시점 연대표(2033/2043/2053), 조심할 시기 연대표(2026/2028/2030). 글자만 있던 우리 리포트의 최대 약점이 이것이다.

넷째, **"종합 희소도 상위 7%" + 격국 명명(일월대명격 등 3개)** — 특별함을 부여하는 장치. 배지 하나로 공유 욕구까지 만든다.

다섯째, **인물 카드.** 배우자상(여성·30대 초반·성격 태그 8개), 귀인 카드(남성·30대 후반·태그 8개), 악인 카드(여성·30대 초반·"과장 충동 불안정 말바꿈 압박 비밀 계산 경쟁" 태그 8개)가 전부 같은 포맷이다. 후기에서 "악인 분석이 최근 거리 둔 사람과 비슷해서 소름"이 나온 그 장치의 실물. 성별·나이대까지 지정해서 실존 인물 대입을 유도한다.

여섯째, **행동 처방의 시간 단위 분해.** 개운법 챕터가 "오늘 바로(조명 바꾸기) → 이번 주 요일별(월 기록/수 정리/금 거절) → 3개월 달별(이번 달 창작/다음 달 관계/다다음 달 협업)"로 내려간다. 재열람 가치와 실행감을 만든다.

일곱째, **문체 리듬.** 캐릭터 화자(현운)의 해요체, 1~2문장 단위의 짧은 문단, 어려운 용어는 TIP 박스, 그리고 모든 챕터가 따옴표 금언 한 컷으로 끝난다. 마지막 챕터는 "현운의 편지"라는 감정적 마무리 + 리뷰 이벤트 + 크로스셀 8개 카드다.

## 3. 우리 대비 판정

우리가 이미 이기는 것: 분량(동급), 과거 정밀도(용용은 과거를 넓게만 짚음 — 우리는 연도 단언), 근거의 정직성(우리는 계산 과정 공개 가능), 심리 서술의 깊이(자유해석 리딩이 더 길고 개인 서사적).

용용이 이기는 것: 시각 장치(챕터당 1개 이상 vs 우리 0), 미래 연도 콕 집기의 상품화(도약/조심 연도를 코너로 명명), 인물 카드(배우자·귀인·악인), 희소도 배지, 행동 처방의 시간 분해, 챕터 리듬(짧은 문단 + 금언 + TIP).

## 4. Phase 3 적용 목록 (어제 ①~⑦에 추가·구체화)

어제 확정한 ① 고민 입력 필드, ② 귀인·악인 분석, ④ 5년 운세 강도 그래프, ⑤ 배우자상 프로필, ⑥ 이메일 발송+재열람, ⑦ 목차 네비게이션은 유지. 실물 확인으로 다음을 추가한다.

⑨ **미래 연도 콕 집기 코너 3종(유료)**: "운이 가장 크게 트이는 해" 1개 + "조심할 해" 최대 3개 + "전환점 연대표". 전부 우리 세운 격발(intensity) 데이터에서 도출 — 근거 있음. 각 연도에 한 줄 이유(충/합/대운 교체) 병기.

⑩ **인물 카드 3종 공통 포맷**: 배우자상·귀인·악인을 같은 카드 UI(성별·나이대·태그 8개·설명 2문장)로. 악인 카드는 천을귀인 반대편·기신 오행 근거. "재미로 보는 참고" 고지.

⑪ **희소도 배지**: 우리는 근거 있는 수치가 실제로 가능하다 — 60갑자×오행 분포 통계로 "수(水)가 0개인 명식은 전체의 N%" 같은 계산 가능한 희소도를 쓴다. 용용처럼 출처 불명 "상위 7%"가 아니라 계산 과정을 보여주는 희소도. ⚠️ 문구 수위는 대표 결정.

⑫ **챕터당 시각 장치 최소 1개 규칙**: 성향/욕구 % 게이지(십신 분포에서 도출), 신강신약 슬라이더, 오행 차트, 운세 타임라인. 렌더러(render.ts → 웹 컴포넌트)에 반영.

⑬ **문단 리듬 가이드**: 자유해석 프롬프트에 "1~3문장 단위 문단, 챕터 끝 한 줄 요약" 힌트 추가(자유도 훼손 없는 수준). 챕터 금언·TIP 박스는 렌더링 레이어에서.

⑭ **개운법(실행 처방) 챕터**: 오늘/이번 주/이번 달 3단 처방. 용신 오행 기반(색·방향·습관) — 엔진 데이터 근거 있음.

⑮ **마무리 편지 + 리뷰 요청**: 감정적 마무리 챕터 후 리뷰/공유 유도. 출시 초기 후기 확보 장치로 중요.

## 5. 정통사주 리포트(2호, 종인 명식 실측) — 직접 비교 결과

원문 전체는 `yongyong/report2-jeongtong-full.txt`. 17챕터 31,295자, 5부 구성: 제1부 지나온 길(과거) → 제2부 타고난 길(원국·오행·십성·신강신약·격국·용신·합충·희귀도·독립화합) → 제3부 열리는 길(대운·세운·재물직업·연애결혼·건강·귀인) → 제4부 흔들리는 길(삼재·악인) → 제5부 용용님만의 길(핵심정리·개운법·심주·Q&A·편지). **유료 리포트가 과거 서사로 문을 연다** — 우리 무료/유료 분할(과거=무료 미끼)과 구조적으로 같은 직관이다.

**계산 검증**: 리포트의 만세력 표·대운표가 우리 엔진과 완전 일치 — 辛未 辛卯 甲午 己巳, 대운 역행·6세 시작, 丁亥 대운 36세(2027년 3월) 진입까지 동일. 세운표(2026~2036 십성·십이운성)도 우리 데이터와 같다. 우리 엔진 정확도가 상용 서비스와 같은 선상임이 다시 확인됐다.

**단 하나의 판정 차이 — 신강신약**: 용용은 종인을 **신약 35/100**으로 판정(화·금·토가 일간을 소모한다는 논리), 우리 엔진은 월지 卯 겁재·양인 왕지득령 특칙으로 **신강**. 점신과 우리는 일치했으니 이건 유파 차이다. ⚠️ 서비스에서는 "유파에 따라 다르게 보는 항목"임을 밝히고 판정 근거(득령·득지·득세 점수)를 공개하는 것이 우리 포지션에 맞다 — 회사 규칙(유파 논쟁 하드코딩 금지)과도 정합.

**과거 서술은 역시 콕 집지 않는다**: "20대 중반부터 30대 초반까지 책임감과 압박을 버텨왔을 것으로 보여요" — 구간+추정형. 자미두수와 동일한 수위. 이로써 확정: **용용은 어느 상품에서도 과거 연도를 단언하지 않는다. 우리 무료 리딩의 과거 연도 단언은 시장에 없는 차별점이다.**

**결정적 발견 — 고민 입력이 리포트 전체 프레임을 만든다**: 구매 시 입력한 고민("20대 중반부터 신용불량…")이 ch16 Q&A 챕터에 그대로 표시되고, 사주 근거와 연결된 답변 + 실질 조언(신용회복위원회 채무조정, 정신건강 상담 권유)이 붙는다. 그리고 ch1의 과거 서사("20대 중반부터 재정적 고통")가 이 입력을 그대로 반영한 프레임이다 — 즉 소름의 상당 부분이 사용자가 직접 준 정보의 재구성이다. ①고민 입력 필드의 위력 실증. 위기 문구(죽고싶음)에는 공감 + 전문기관 안내로 대응하는 것도 확인 — 우리도 안전 대응 로직 필수.

**금액 그래프 실물 확정**: "향후 5년 재물운 — 해마다 최대로 모을 수 있는 금액" 2026년 8,000만 → 2027년 1.5억 → 2028년 3억 → 2029년 5억 → 2030년 8억. 근거 없는 수치 맞다. 어제 판정 유지: 우리는 금액 대신 근거 있는 운세 강도 지수.

**희소도 장치의 사주 버전**: "사주 희귀도 A+등급 · 전국민 중 1.7%" + S/A/B/C 등급표 + 근거 각주(오행 4개 25% 대칭 + 무인성). 검증 불가한 수치지만 형식은 그럴듯하다. 우리는 실제 계산 가능한 통계(오행 분포 조합 빈도)로 정직한 버전을 만든다 — ⑪ 유지.

**인물 카드에 MBTI·키·직업계열까지**: 배우자(여 30대 초반·INFJ/INTJ·163cm·교육/연구/행정), 귀인(여 30대 중반·INFJ/INTJ·163cm·교육/연구/자산관리), 악인(남 30대 후반·ENTJ·178cm·투자유치/동업). 눈에 띄는 허점: **배우자와 귀인 카드가 사실상 같은 인물상** — 템플릿 재사용 티가 난다. 우리는 카드마다 명식 근거를 달리해 이 허점을 피할 수 있다.

**그 외 확인된 장치**: 근거 각주 시스템("근거 2"~"근거 14" — 본문 주장에 번호 달림), 참고 문헌 표기(적천수·자평진전), 한자 코너명(往事·緣由·原局·開運…), 삼재 3년 연차별 주의(들/눌/날삼재), "심주(心柱)"라는 다섯 번째 기둥 창작 개념, 개운법의 시간 분해(내일 일진 → 이번 주 7일 일진표 → 3개월 월운), 월 단위 연애 흐름 그래프(9~10월 콕), 직장인 75% vs 사업가 45% 게이지, 마무리 편지(현묵) + 리뷰 이벤트 + 크로스셀.

## 7. 최종 결론 — 3개 리포트가 말해주는 것

용용의 소름 공식은 ①사용자가 입력한 고민의 재구성(개인화의 대부분) ②미래 연도·월 콕 집기(과거는 절대 안 집음) ③챕터당 시각 장치·수치화 ④비유로 쉬움 유지 ⑤귀인·악인·배우자 실존 인물 대입 장치다. 우리는 계산 레이어에서 이미 동급 이상(만세력·대운 완전 일치)이고, 과거 연도 단언이라는 용용이 안 하는 무기가 있다. 남은 일은 ①고민 입력을 받고 ②시각 장치를 렌더러에 얹고 ③미래 로드맵 코너를 만들고 ④안전 규칙을 박는 것. 대표실 승인 대기 항목: 희소도 문구 수위, 금액 vs 지수, 미래 콕 집기의 무료/유료 배치, 유파 병기 방식, 지시형 솔루션 수위, 후속 질문 채팅 도입.

이 분석으로 용용사주 3개 리포트 대조는 완료. 다음 단계는 PHASE3-SPEC 갱신(개발팀) → 웹 구현.
