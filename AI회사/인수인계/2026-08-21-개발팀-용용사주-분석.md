# 용용사주(yongyong.ai) 분석 — 소름의 구조와 우리 적용안

## 1. 서비스 구조

**모델: 한 개의 엔진 + 수십 개의 "스킨".** 사주·자미두수·타로·점성술·베딕까지 체계를 넓히고, 그 위에 목적별 상품(재회·궁합·임신·결혼·재물·직업·영재·유혹)과 캐릭터별 상품(만신할매, 소녀 도사 단하, MZ역술인 이채린, 도깨비, 삼신할매)을 곱해서 30개+ 상품을 찍어냄. 슬로건이 **"정확도 200%"** — 네가 쓰던 그 표현의 출처가 여기다.

## 2. 소름을 만드는 장치 (후기에서 실증된 것)

후기 3건에서 사용자가 "소름"이라고 지목한 지점:

1. **과거 연도 맞추기** — "특히 2025년에 힘들었던 거 맞추니까 소름이 돋으면서 훅 빠졌다", "20대 중반에 압박감과 책임감이 커졌다는 내용도 맞았다" → **우리 방향(연도 콕 집기)이 시장에서 검증된 게 맞다.** 70%면 이미 근접.
2. **내면 온도차 짚기** — "겉으로는 괜찮은 척하지만 속으로는 혼자 다 책임지려는 성향", "타인이 보는 모습과 실제 내면의 온도 차이" → 우리 자유해석이 이미 하는 것.
3. **귀인·악인 분석** — "최근 거리를 두려고 했던 사람과 악인 분석이 묘하게 비슷해서 깜짝 놀랐다" → 독자가 실존 인물을 대입하게 만드는 장치. 우리에게 없음.
4. **"일이 하기 싫은 이유 2가지" 같은 좁은 단언** — 다른 후기: "진짜 다 맞는 말이라 소름".
5. **배우자 프로필 구체화** — 외모·성격·직업·**MBTI**까지. "이분은 대체 어디 계세요ㅋㅋ" — 공유 욕구를 만드는 재미 장치.

## 3. 리포트 형태 (단하 정통사주 기준)

- 8대 영역: 명식 / 연애 / 재물 / 결혼 / 성취 / 관계 / 건강 / 개운법 — 10챕터 6,000자+
- **그래프·차트 중심**: 오행 차트, 10년 운세 흐름 도식, **향후 5년 재물운 그래프에 금액까지 표시**("2028년 6억, 2029년 8억 5천")
- 목차 네비게이션(원하는 부분만 골라 읽기), 이메일 발송 + 재열람
- 권위 장치: "궁통보감·토정비결 고서 기반", "역술가 18인 검증", "12만개 상담 데이터"
- 캐릭터 화법으로 어려운 용어를 부드럽게 (단, 내용은 깊음)
- 나쁜 내용도 포함("결혼운·건강운은 주의 필요") — 신뢰 장치
- 만신할매 상품은 입력에 **"문제 및 관심사"** 필드가 있음 — 고민을 받아서 리딩을 그 중심으로 전개

## 4. 우리 적용 판정

### 바로 적용 (Phase 3에 반영)

| # | 항목 | 근거 |
|---|---|---|
| ① | **고민 입력 필드** ("요즘 제일 큰 고민이 뭐예요?" 선택 입력) | 레퍼런스 채팅이 소름이었던 숨은 이유가 맥락이었다. 만세력 표에 고민 한 줄만 얹어도 자유해석의 타격 정밀도가 뛰어오른다. 구현 비용 거의 0 |
| ② | **귀인·악인(조력자·경계인) 분석** | 천을귀인 방향·기신 오행으로 도출 가능 — 엔진 데이터로 근거 있음. 독자가 실존 인물을 대입하는 순간 소름이 됨 |
| ④ | **5년 운세 강도 그래프** | 우리 격발 강도(intensity) 데이터가 이미 있음 — 근거 있는 수치라 회사 규칙과 충돌 없음. 렌더러에 라인 차트 추가 |
| ⑤ | **배우자상 프로필 (성향·만나는 경로·시기 + MBTI 추정)** | 재미·공유 장치. "재미로 보는 참고" 고지와 함께 |
| ⑥ | **이메일 리포트 발송 + 재열람** | PHASE3-SPEC에 영구링크 있음 — 이메일 발송 추가 |
| ⑦ | **목차 네비게이션 + 챕터 앵커** | 리포트 뷰어에 반영 |

### ⚠️ 사람 결정 필요

| # | 항목 | 쟁점 |
|---|---|---|
| ③ | **재물 그래프에 금액 표시** ("2029년 8억 5천") | 소름·공유 효과는 확실하나 **회사 규칙 1(확인되지 않은 수치 금지)·표시광고 리스크와 정면 충돌.** 근거 없는 금액 예측은 우리 "정직한 계산" 포지션을 훼손. 대안: 금액 대신 상대 강도(운세 지수)로 |
| ⑧ | 캐릭터 페르소나 (단하 같은 화자 캐릭터) | 브랜드 방향 결정 — "정밀·계산 공개" 포지션과 조합할지. 페르소나는 나중에 스킨으로 얹을 수 있으니 출시 후 판단 가능 |

### 채택 안 함

- "역술가 18인 검증" 류의 검증 불가 권위 문구 (규칙 위반) — 우리는 대신 **계산 과정 공개**가 권위 장치
- 상품 30개 분화 — 출시 전엔 집중이 우선 (회사.md '하지 않을 일')

## 5. 핵심 결론

용용사주의 소름 = **① 과거 연도 맞추기(우리도 도달) + ② 좁은 심리 단언(우리도 도달) + ③ 귀인·악인/배우자상 같은 "실존 인물 대입 장치"(우리에 없음) + ④ 고민 입력이 주는 맥락(우리에 없음)**. ③④가 남은 30%의 정체일 가능성이 높다. 여기에 그래프·차트 가독성이 체감 품질을 올린다.

종인이 받은 실제 리포트가 오면: 분량·차트 구성·단언의 수위·틀린 부분을 대조해서 이 분석을 확정한다.
