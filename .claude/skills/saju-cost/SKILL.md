## 실측 원가

| 항목 | 원가 |
|---|---|
| 프리미엄 최저 | 4,443원 ($3.20) |
| **프리미엄 평균 (n=6)** | **5,743원 ($4.13)** |
| 프리미엄 최고 | 8,101원 ($5.83) |
| 무료 티저 | 311~395원 |
| 무료 티저 (캐시 히트) | **0원** |
| 건강운 단품 (6페이지) | 879원 |

**고민 개수가 원가를 좌우한다.** 고민 5개 + 구체 계획 요청 = 8,060원(40페이지),
고민 3개 = 4,443원(25페이지). 접수 단계에서 고민 수를 관리하면 원가가 관리된다.

## ⚠️ 이 숫자의 한계

원가는 코드에 **하드코딩된 단가**로 계산한다:

```ts
const RATE = { in: 15, out: 75, cw: 18.75, cr: 1.5 };  // USD per 1M
const KRW_PER_USD = 1390;
```

**콘솔 실청구액과 대조가 필요하다.** 어긋나면 아래 마진·손익분기를 전부 다시 잡아야 한다.
이 대조는 아직 안 됐다.

## 손익분기 전환율 — 가장 중요한 숫자

| 무료 구간 설계 | 무료 건당 | 손익분기 전환율 |
|---|---|---|
| 구 설계 (완결 과거리딩) | 1,379원 | **17.31%** ← 목표 3%와 격차가 치명적이었음 |
| **신 설계 (티저)** | **311~395원** | **4.96%** |
| 신 설계 + 캐시 20% | 316원 | 3.97% |
| 신 설계 + 캐시 30% | 276원 | 3.47% |

**무료가 많이 팔릴수록 손해인 구조를 피하는 게 핵심이다.** 프리미엄 가격을 올려도 이 문제는
안 풀린다 — 무료 이용자는 애초에 돈을 안 내기 때문이다. 레버는 **무료 원가**다.

**캐시 적중률 현실**: 명식 공간이 커서(출생연도 1개당 365일 × 12시지 × 성별 2 = 8,760가지)
서로 다른 사람끼리 겹칠 확률은 낮다. 실제 적중은 **같은 사람의 재요청**(새로고침·뒤로가기)에서 나온다.
원가 절감의 주역은 캐싱이 아니라 **티저 축소**다.

## LLM 호출 코드를 만들 때 — 필수

1. **usage 집계를 반드시 넣는다.** `input_tokens`, `output_tokens`,
   `cache_read_input_tokens`, `cache_creation_input_tokens` 전부.
   집계 없는 호출을 추가하면 원가가 보이지 않는 구멍이 생긴다.
2. **프롬프트 캐싱(`cache_control`)을 쓴다.** 만세력 블록처럼 턴 간 재사용되는 큰 입력에 붙인다.
3. **max_tokens를 용도에 맞게 잡는다.** 무료 티저를 16000 → 4000으로 줄인 것만으로 원가가 71% 내려갔다.
4. **재시도 로직이 원가를 몇 배로 만들 수 있다.** 이어쓰기는 이미 받은 텍스트를 살려서 넘긴다
   (`streamWithWatchdog` 참고).

## 가격 (회사.md §1 확정)

**프리미엄 14,900원.** 인상 논의는 대표 결정 사항이다. 참고로 9,900~19,900원이 앱 유료 상품
주력 구간이고, 19,000원 이상은 크몽 사주 상담 구간과 겹치기 시작한다.

**단품 라인 가능성**: 건강운 단품이 879원에 6페이지가 나왔다. 프리미엄의 1/6 원가라
3,900원대 단품(재물운만/연애운만/건강운만)은 마진이 오히려 더 좋다. v2 라인업(궁합·신년운세)보다
만들기도 쉽다 — 프롬프트 하나 + 스크립트 하나.
